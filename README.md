# PikPak Desktop

独立的 PikPak 桌面客户端原型，使用 Electron + Vue 3。

## 运行

```powershell
cd pikpak-client
npm install
npm run dev
```

生成 Windows 便携版：

```powershell
npm run package:win
```

产物位于 `release-<版本>-win/PikPak-Desktop-<版本>-portable.exe`。

生成 macOS Apple Silicon 安装包与 ZIP：

```bash
npm run package:mac
```

产物位于 `release/PikPak-Desktop-<版本>-mac-arm64.dmg` 和对应 ZIP。未配置 Apple Developer ID 时产物不会签名或公证。

## 当前能力

- Windows 桌面文件管理界面
- 官方网页登录窗口与授权请求捕获
- 使用系统安全存储加密保存访问令牌
- 加密持久化官方会话对应的设备标识，重启后保持授权与验证码签名一致
- 浏览已连接账户的目录和文件
- 使用主文件列表和面包屑浏览目录；不提供目录树，也不会为目录树发起额外请求
- 通过隔离的官方页面桥接提取 opaque token，浏览公开分享的深层目录
- 图片缩略图、媒体直链与元数据显示
- 内置视频和音频播放器
- 视频清晰度切换保留进度，支持倍速、线路自动回退和常用键盘播放控制
- 记忆视频倍速、音量和静音并支持画中画播放；视频始终按原比例完整适应播放器窗口
- 播放时阻止系统显示器休眠，暂停或关闭后自动释放；HLS 网络和解码错误自动恢复
- 自动识别 UTF-8、UTF-16 和 GB18030 中文字幕编码，本地及在线支持 SRT、VTT、ASS/SSA
- 播放地址失效时自动从 PikPak 刷新网盘或分享媒体直链，并保留原播放进度继续加载
- 播放时自动隐藏顶部工具条和鼠标，移动鼠标或暂停后恢复；双击视频切换全屏
- 本地下载任务、进度、取消与完成后定位
- 自动分页加载完整目录
- 新建文件夹、重命名和移入回收站
- 下载历史持久化、异常退出恢复标记和记录清理
- 当前目录搜索及名称、大小、时间排序
- 原创 Windows 应用图标与渲染失败错误页
- 复制、剪切并粘贴到其他目录
- 回收站浏览、恢复和永久删除
- 主进程统一处理 PikPak API 和 captcha 签名
- 离线下载创建时选择网盘保存目录
- 创建分享时选择有效期以及公开或提取码访问
- 单项操作通过右键菜单与底部多选操作浮层完成，不占用页面顶部工具栏；支持 Command/Ctrl 点选、Shift 范围选与鼠标框选

## 当前限制

- 网页登录依赖 PikPak 当前登录页面；仍保留手动 Access Token 作为高级兜底。
- 分享 API 不公开子目录所需的 opaque token，因此分享的深层目录浏览需要后续加入内置网页会话桥接。
- PikPak 接口并非稳定的公开桌面 SDK，站点升级后可能需要适配。
